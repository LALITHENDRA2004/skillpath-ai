
# SkillPath AI

An AI-powered personalized learning platform that helps users create learning roadmaps, practice concepts, track progress, and manage study schedules.

## Project Objectives

- Generate personalized learning roadmaps based on skill level and target dates.
- Provide concept-wise learning resources, tasks, and assessments.
- Evaluate answers and programming submissions.
- Create daily study schedules based on available time.
- Track completed tasks, assessment scores, and learning progress.
- Suggest timetable adjustments while keeping the user in control.
- Provide AI-assisted explanations and practice questions.
- Identify weak topics and recommend areas for improvement.

## Development Approach

The project is developed incrementally. Each part is implemented, tested, and committed to Git before moving to the next part.

## Planned Modules

1. Project setup
2. Frontend foundation
3. Flask backend and MySQL
4. User authentication and learning goals
5. Learning roadmap generation

7. Personalized study scheduling
8. Email reminders
9. User-controlled rescheduling

## Cost Considerations

The project prioritizes free development tools and open-source technologies. Google Colab will be used for ML experimentation. Paid AI APIs are not required for the initial implementation.
